# Suggested V0.2 Backlog

Items are deliberately deferred until real-user feedback validates the MVP.

1. Add a clearer per-field saved-state indicator without increasing page clutter.
2. Improve fingerprints for repeated dynamic forms while preserving query-free metadata.
3. Add opt-in support for same-origin iframes and carefully tested editor adapters.
4. Add a configurable global pause and per-site retention overrides.
5. Add export/import of locally encrypted drafts only after a focused key-management threat model.
6. Investigate storage-write coordination across simultaneous tabs.
7. Add automated Chromium end-to-end tests for refresh, restart, SPA, and duplicate-tab flows.
8. Improve accessibility testing across high contrast, zoom, and screen readers.
9. Localize popup, options, and recovery strings.
10. Evaluate Firefox support behind a small compatibility layer.

Cloud sync, accounts, analytics, AI, and payments remain out of scope unless the product direction changes explicitly.
